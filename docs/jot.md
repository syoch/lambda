# Jot

Jot は 0, 1 のビット列でラムダ式を構成する記法。
すべてのビット列は構文エラーなく、ラムダ式に変換できる

## ラムダ式への変換ルール

`X` は任意のラムダ式。
`J[X]` は `X` を Jot で表したもの。

- `(空)` = `I`
- `J[X]0` = `X S K`
- `J[X]1` = `S (K X)`

例えば後置の `S`, `K` は以下のように表される:

```plain
  E K
= E (S K S K)
= E ((S K S) K)
= B E (S K S) K
=

  S
= K S K
= S K S K S K
= 000
```

## 状態の適用

Jot はその言語の特性上、状態について変形をしていくものと解釈ができる。
`E; X` は状態 E に Jot ビット列 X を適用したものとする。
